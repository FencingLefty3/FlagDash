# DashFlag

Terminal Based Puzzle Game.
```
    
          ▀▀▀▀▀ ▀     ▀▀▀▄  ▀▀▀▀▀
▀▀▀▀ ▀▀▀▀ ▄ ▀▀  █     ▄ ▀▀█ ▄ ▀▀█
          █      ▀▄▄▄ ▀   ▀  ▀▄▄▀    
```
## How to Installing

Install from: `pip install dashflag` command.

Or: `Releases` > download > `pip install <path>`.

## Playing

Run `DashFlag` in terminal. > `New` Game > Enter `Save Name` > Start!

## Tips

### Hints
Entering `hint` in the question input will give a hint. You can request multiple times. Diffrent questions have diffrent numbers of hints.

### Loading Saves

Run `DashFlag` in terminal. > `Load` Game > Enter Save `Number`> Play. (Or `DashFlag load`)

### Deleting Saves

Run `DashFlag` in terminal. > `Load` Game > `Delete` > Enter Save `Number`> Confirm. (Or `DashFlag delete`)

### Closing

Games save after every level. Current level is displayed next to save number in load game. (`Exit` From most menus. `Ctrl + C` always exits, but may not save.)
